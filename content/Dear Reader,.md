
This semester I took a Professional and Technical Communications class at Central New Mexico Community College(CNM). For this class we had to create a [resume and cover letter](resume), a [poster](poster) about email etiquette, a [[Technical document]], and this [website](index).

## Resume and Cover Letter
The resume and cover letter are essential for joining the workforce and I was grateful for a chance to improve my already existing resume and learn how to improve my cover letter writing skills.

## Poster
The poster is a short email etiquette guide. I created it using Inkscape, which was a software tool I had been thinking about learning for a while, but never really had a need. (Learning to use Inkscape for this project was fortuitous, because it allowed for me to sign up for a laser cutting course at Fuse Makerspace, which then allowed me to sign up for a class about making and using a backstrap loom.)

## Technical Document
The technical document shows how change the format of a video and how to lower the resolution to make it smaller using VLC. This class required several video discussion posts. When I attempted to make the first one using my laptops webcam it came out as a .mkv file, which CNM's learning management system would not accept. I remade the video using my phone's camera, but this wouldn't upload properly because the resolution was too high. I did some googling and found out that VLC could fix both the formatting and size problems using VLC.
